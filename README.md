# hiimkoreanpeople.github.io

HTML, CSS, JavaScript를 배우면서 만든 첫 웹사이트입니다.
GitHub Pages로 올라가고 있어요.

- 주소: https://hiimkoreanpeople.github.io/
- 만든 사람: 서준 (@hiimkoreanpeople)

## 파일 설명

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면의 내용과 뼈대 (제목, 문단, 버튼) |
| `style.css` | 색, 글꼴, 여백, 움직임 같은 디자인 |
| `script.js` | 버튼을 눌렀을 때 일어나는 동작 |

## 들어 있는 기능

- 다크 모드 / 라이트 모드 전환 (선택한 테마를 기억합니다)
- 인사말을 바꾸는 버튼
- 클릭 횟수 카운터 (숫자를 기억합니다)
- 휴대폰 화면에 맞춰 바뀌는 반응형 배치
- 스크롤할 때 부드럽게 나타나는 효과

## 직접 고쳐 보기

1. 파일을 엽니다.
2. 글자나 색을 바꿔 봅니다.
3. 저장한 뒤 새로고침하면 바뀐 모습을 볼 수 있어요.

`style.css` 맨 위 `:root` 안의 색상 값을 바꾸면 사이트 전체 색이 한 번에 바뀝니다.
